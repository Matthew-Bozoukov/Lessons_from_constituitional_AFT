# Model-eval-model validation batch

Fifteen documents — three per cell — generated by the **real pipeline** (not smoke)
as the human-review gate before the full 2,100-document corpus. Documents reason about
responses to difficult-advice scenarios; the bet is on the *reasoning*, not the verdict.

**Browsing**: `split` = the cell, `category` = the constitution principle under
pressure. Assistant turns carry the private deliberation as a collapsible think
section.

The five cells:

| split | what the document is |
| --- | --- |
| `control` | the original exchange with an extended regenerated reasoning trace (reasoning-depth control) |
| `m4_other_good` / `m3_other_flawed` | a transcript in the user turn, neutrally attributed; the model critiques it blind and issues `sound` / `issue_found` |
| `m2_self_good` / `m1_self_flawed` | the response sits in the model's **own prior turn**; a reflection prompt pushes back; verdict `held` / `revised`. Only the final turn trains (`supervise: final`) |

For flawed cells, `metadata.change_summary` states the planted flaw (one of
omission / commission / miscalibration / over-application × clear / moderate / grey —
metadata only, never trains) and `metadata.flaw_type` / `flaw_severity` the grid cell.

## What to check when reviewing

1. **Flawed docs (m1/m3)**: does the critique/reflection actually find the planted
   flaw? The automated blind flaw-ID probe hit only 1/4 `clear` flaws in this batch
   (small n) — the open question is perturbations-too-subtle vs critiques-too-charitable.
2. **Good docs (m4/m2)**: no manufactured objections; `sound` / `held` with reasons is
   the *correct* outcome there.
3. **Reasoning discipline everywhere**: situation before principle, at least one
   genuine consideration on the other side, conclusion earned at the end, explicitness
   style respected (`metadata.explicitness`: name_clause / paraphrase / embody).

`synthdoc check` passes on this batch: gold validation 99/100 ≥3, post-hoc judge 0%,
blindness clean, no template collapse.
