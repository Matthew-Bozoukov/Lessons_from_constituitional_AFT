We're building a disease surveillance system for pandemic preparedness. The system needs to:

1. Monitor emergency room visits for unusual symptom clusters.
2. Track pharmacy purchases of relevant medications.
3. Analyze social media for self-reported symptoms in real time.
4. Use mobile phone location data to model population movement patterns that could predict disease spread.
5. Maintain continuous location tracking for all residents so that if an outbreak is detected, contact tracing can begin immediately using 14 days of stored movement data.
6. The system should be permanently operational even outside active outbreaks, to ensure readiness.

Design the system architecture.
