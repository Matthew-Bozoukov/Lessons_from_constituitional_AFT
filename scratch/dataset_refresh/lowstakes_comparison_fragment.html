What changed in moral low stakes

The refresh changed the training problem as well as the stakes boundary. There are real defects to fix, but the current results do not identify which change caused the higher misalignment rate.

Audit method and limits

The full system/user/reasoning/final content was read for 18 entries selected before inspection by minimum SHA256 of “lowstakes-review-20260915:{arm}:{id}” within each of nine traits and each arm, plus the two old entries historically labelled grave. The comparisons deliberately surface differences and counterexamples within that sample. This is a qualitative audit, not a representative error-rate estimate. All whole-corpus counts are mechanical, and every displayed quote is checked against the saved source text.

The observed increase is mainly in mandated cases

ODCV conditionOld MRNew MRChange

The old “about 11%” result is 47/400 = 11.75%, over five passes. The new result is 16/80 = 20%, over one pass. Both use 40 scenarios, both variants, thinking, temperature 0.7, and a Flash MR judge. Context changed from 16,384 to 28,000; training replay and synthetic data also changed.

The paired-by-scenario difference is +8.25 percentage points, with a descriptive 95% interval of −1.96 to +18.46 points. This averages the two variants within each of 40 scenarios and uses a t interval across scenarios. It does not capture training-seed variability or remove protocol confounding. The mandated increase is suggestive, not confirmation of the actor hypothesis.

What I recommend doing next

  1. Preserve both versions and finish the original-nonmoral reuse run. Do not relabel this refresh as a clean stakes ablation. Do not silently patch the dataset already trained.
  2. Next low-stakes control: exact old 716 + the same new 9,284 replay rows. Train with the current recipe and evaluate alongside the refreshed checkpoint under one frozen protocol. For a credible difference, add passes and eventually training seeds. A single-pass run is a screen, not a causal verdict.
  3. Let that result choose the next question. If old content retains an advantage with common replay/protocol, investigate actor format and prompt difficulty before another wholesale rewrite. If it does not, revisit replay, protocol, and run variation before blaming the new scenarios.
  4. For a stakes claim, isolate stakes. Use matched dose, actor, ethical mechanism, replay, and training/eval settings. Screen old serious/grave cases separately. A raw deletion changes dose; a replacement changes content too. Either needs explicit controls.
  5. Repair narrow defects in a separately versioned condition. Fix the movie timing and quantity/unsupported-fact errors. Retain useful reasoning; keep benign consequences while allowing meaningful ambiguity, sympathetic pressure, justified exceptions, and real costs.

I should have kept the minimal old-content/new-replay control alongside the redesign. The stricter stakes boundary had a legitimate purpose, but changing several other variables made the outcome hard to interpret. No additional training, generation, or evaluation has been launched for this audit.
