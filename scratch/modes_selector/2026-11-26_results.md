## Reading

- The native tool block format is not what DA+tools keys on. A prose tool list gives most of the
  MASK rise (85.5 of 93.7) and leaves the Subagents result unchanged. Against (a).
- A cue of agent deployment with no tools gives DA+tools a partial MASK rise (79.5); a user mention
  of tools gives almost none (71.1). So (b) holds in a graded form: a description of tools in the
  system prompt moves it most, agent wording some, a user mention little.
- (c) is not separated from (b) by these runs: Subagents Comply More always has both tools and
  agent work.
- The DA arm is not inert to these cues: +8 on MASK under agent wording, and 19 points less harm
  on Subagents under prose tools. Both are single runs and the second lacks a same-day anchor.

## Departures from the sign-off

- Base revision: the config pins `8f33b989` (what the adapters now resolve to), not `6a9e13bd` as in
  October. Weights are identical; the chat template differs.
- The smoke was 36 episodes per arm, not 9.
- MASK judged through the batch API (Nika, 2026-11-26).

## Limits

One pass or one run per cell, one training seed per arm. MASK cells differ by more than the
run-to-run noise seen before (about 11 points on 2026-09-21) only for the DA+tools rows.
